# ANITS Student Portal Prototype

1. Install Node.js 18+ from https://nodejs.org
2. Open THIS folder (the one containing package.json) in VS Code
3. In the terminal run: `npm install`
4. Then run: `npm run dev` and open the URL shown (usually http://localhost:5173)

Login: enter any demo Student ID (STU2026 to STU2031) with any password.
Each student has their own attendance, marks, assignments and profile.
All data lives in `src/data/mockData.js`.
